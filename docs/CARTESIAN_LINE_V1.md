# Независно планирање Декартове путање — v1

## Намјена

Прва функционална верзија планира **праву линију између двије XYZ позиције** у свјетском координатном систему, умјесто да TCP путању добија из раније задатих углова зглобова. Затим нумеричком **3D инверзном кинематиком** проналази угаоне конфигурације за тачке на линији и користи ту путању као референцу постојећем симулационом PD+G или CTC контролеру.

- TCP у овом примјеру означава **координатни почетак тијела `link7`**, а не калибрисани алат. За прави врх алата потребан је посебан `site`/трансформација.
- **Оријентација није задата нити регулисана**. Она се само снима као одступање од почетне оријентације.
- Јакобијан је позициони `3 × 7`. Инверзна кинематика је пригушена метода најмањих квадрата са ограниченим кораком и провјером дозвољених углова. Седам зглобова оставља 4 степена редундантности за 3D позициони задатак.
- Путања у XYZ простору користи квинтичко временско скалирање. Прорачунате зглобне међутачке се повезују квинтичким сплајном; провјеравају се границе зглобова и тачност линије између тачака.
- Не изводи се провјера колизије, силе контакта, безбједности на стварном роботу нити регулација оријентације.

## Покретање из Git репозиторијума

Све потребне Python датотеке и модели већ су укључени у репозиторијум. Команде се покрећу из коријенског директоријума пројекта.

```bat
conda env create -f environment.yml
conda activate robotics
python -m unittest discover -s tests -v
python scripts\verify_models.py
python scripts\run_cartesian_line.py --delta-xyz 0.02,0,0 --controller pd_g
```

За визуелизацију додај `--view`. Алтернативно се може користити `--controller ctc_tuned_fast`, без мијењања постојећих параметара. Циљ се задаје у метрима помоћу `--delta-xyz` или апсолутном координатом `--target-xyz`. Почетна конфигурација је `DEFAULT_GOAL`, а може се промијенити преко `--start-q`.

## Услови пролаза прве функционалне провјере

1. `IK preflight PASS` и прецизност планираног пута унутар **1 mm** у густим међутачкама, без прекорачења углова. То провјерава **план**, не стварни симулациони одзив.
2. Симулација се заврши без NaN, прекорачења сигурносне границе брзине и без неочекиваног изласка из прегледача.
3. Сниме се `planned_waypoints.csv`, `time_series.csv`, `config_and_summary.json` и графови, у новом временски означеном директоријуму.
4. Поређење XYZ путање са стварним XYZ кретањем. **Не тврдимо унапријед да праћење мора бити испод 1 mm**: то зависи од контролера, модела и трења. Лошији резултат се евидентира као ограничење, не као позив на бесконачно подешавање.

## Накнадна независна провјера

Након почетне функционалне провјере, пројекат је тестиран из независне Git копије у новом Conda окружењу. Успјешно је прошло свих 12 јединичних тестова, као и провјера усаглашености динамичких модела MuJoCo и Pinocchio.

За 3D планирање тестирано је помјерање од +20 mm дуж свјетске X осе са контролером PD+G. Свих 151 IK међутачака прошло је провјеру. Највећи резидуал позиционе IK износио је приближно 0,019 mm, а завршна позициона грешка симулационог одзива приближно 1,777 mm. Засићење управљачких момената није забиљежено.

Независно 6D планирање позиције и оријентације такође је имплементирано и тестирано; видјети `CARTESIAN_POSE_V1.md`.
